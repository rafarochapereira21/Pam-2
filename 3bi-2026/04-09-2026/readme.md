# Calculadora de Juros Compostos

Aplicativo simples feito com React Native + Expo para calcular juros compostos.

## Campos

- Valor inicial
- Taxa de juros anual ou mensal
- Periodo em anos ou meses
- Investimento mensal

## Resultado

O app mostra:

- Montante final
- Total investido
- Juros acumulados
- Periodo calculado em meses

## Como executar

```bash
npm install
npm start
```

Depois, use o Expo para abrir no Android, iOS ou navegador.
